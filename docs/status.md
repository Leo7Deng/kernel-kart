- Determinism (2026-10-29): the golden recorded on the user's Mac failed 18 cases on the x86 VM (Kernel Pretzel, Assembly Line, Recursion Ridge, all 6 each, even run alone). Not a leak: on HEAD every race matched alone, shuffled or reversed in one process. Cause: V8's Math.sin/cos/exp/atan2/pow (and `**`) are compiled C (x86 V8's sin already differs from fdlibm's in ~13% of calls), and an arm64 build can round the last bit differently. Gameplay now uses `js/detmath.js` (pure-arithmetic fdlibm/musl ports, within 1 ulp of the engine's for sin/cos/log, identical for exp/atan; `hypot` a plain sqrt; pow 43 ulp worst); the whole golden was rewritten, and races run a touch faster (hypot). Only leak found: race-drift's no-drift zones were cached per track with the first run's BOT margins (a measurement trying other margins got stale ones). Time-trial ghosts are recorded poses, so old ghosts still play back; no `rev` bump.
